# Releasenotes

Zet vóór een release een bestand `v<versie>.md` in deze map (bijv. `v1.0.3.md`). De bouwstap (*Losse app bouwen* → *Release maken*) gebruikt dat als tekst van de release. Zonder bestand worden de commitberichten sinds de vorige versie gebruikt.

De app toont de regels die met `- ` beginnen in de updatemelding (de eerste 5 zichtbaar); kopjes (`## …`) en regels met een link worden daar overgeslagen. Zet het belangrijkste dus bovenaan en houd regels kort.
