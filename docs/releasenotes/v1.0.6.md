## Nieuw in deze versie
- Automatische back-up: elke dag en vóór elke update, de laatste 10 terug te zetten via Menu → Back-up
- Pincode: anderen op het netwerk kunnen alleen meekijken, bedienen kan pas na de pincode
- Op de computer waar PTZ Control draait is nooit een pincode nodig
- Tabletweergave: grote tegels en camerakeuze onderin, gaat op een tablet vanzelf aan
- Menu past nu ook op een telefoon helemaal in beeld

## Let op
- Pincode instellen via Menu → 🔒 Toegang (pincode); daarna moeten andere apparaten hem één keer invoeren
