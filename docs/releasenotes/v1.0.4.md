## Nieuw in deze versie
- Bijwerken werkt nu ook als PTZ Control uit een gewone map draait (bijv. als ZIP gedownload, zonder git)
- Nu bijwerken stapt dan over op de losse app; het Dock-icoon blijft gewoon werken
- Je instellingen, presets en foto's gaan naar een vaste plek buiten de app en blijven bij elke update bewaard
- Werkt ook als git op de Mac niet geïnstalleerd is

## Let op
- Draai je PTZ Control uit een map zonder git: deze versie één keer zelf ophalen, daarna gaat bijwerken vanzelf
- De oude instellingen blijven als reservekopie in de map staan (cameras.json.overgezet)
- Niet bijwerken tijdens een dienst: de bediening is dan even weg
