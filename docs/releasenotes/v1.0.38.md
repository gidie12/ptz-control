## Nieuw in deze versie
- Xbox-controller: kies in de Xbox-kaart bij *Bestuurt* welke camera de controller bestuurt. Die blijft dan vast, ook als je op het scherm een andere camera kiest; *Wisselt mee* = zoals vroeger
- Optioneel een Xbox-knopje in elke kolomkop om de controller snel vast te zetten (Menu → Instellingen → Weergave → Xbox-knop)
- Focus per preset: autofocus of handmatige focus wordt bij opslaan bewaard en bij oproepen teruggezet; per preset aan te passen in het presetvenster
- De tekst GESELECTEERD en AANGEPAST staat standaard niet meer op de tegels, alleen de indigo rand (aangepast = gestippeld); aan te zetten via Menu → Instellingen → Weergave → Labels
